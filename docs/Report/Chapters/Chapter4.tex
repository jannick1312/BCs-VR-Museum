\chapter{Concept}
\label{ch:concepts}

\begingroup
\setaftersecskip{6pt}
\setlength{\emergencystretch}{2em}
Unlike a list or grid, the VR museum places search results in a space that visitors can walk through. It arranges images, videos and 3D models as an exhibition. Users can move freely, view exhibits from different angles and select one to start another search. The room stays the same, but the exhibition changes with each query. This creates a continuous process in which users can explore results and use them to continue their search.

The first part of this chapter describes the main parts of the system. It then introduces the interaction model and explains how search results become an exhibition based on the available space. The last section describes how users enter the museum and the exploration cycle.

\section{Conceptual Architecture}
\label{sec:concept-architecture}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.9\textwidth]{Figures/ch04-01-conceptual-architecture.pdf}
  \caption[Conceptual architecture of the VR Museum]{
    Conceptual architecture of the VR museum. The frontend shows the museum and handles user interaction. The application logic connects the frontend to the search system and the required media files.
  }
  \label{fig:conceptual-architecture}
\end{figure}

Figure~\ref{fig:conceptual-architecture} shows the conceptual architecture of the VR museum. The frontend presents the museum room and handles input. It supports several VR platforms, but the room, search process, and basic interactions stay the same. Visitors can enter text queries, view exhibits, and select an exhibit as the starting point for a similarity search.

The application logic coordinates a search. It turns the input into a query, considers the selected media types and available space, and prepares the results for the frontend. The retrieval backend performs the semantic search and returns matching content. It does not decide where or how that content appears in the museum.

The collection is prepared before visitors use the museum. The retrieval backend searches the stored representations, while media delivery provides the files that are shown as exhibits. This separation gives each part one clear role. A part can be replaced if the new component provides the same interface and media formats.

\section{Search-Based Exhibition}
\label{sec:concept-museum-model}
\label{sec:concept-exhibition-generation}

A query searches the prepared collection and returns a ranked list of results. Instead of showing the list directly, the museum uses the results to create an exhibition in the virtual space.

\subsection{Collection, Queries and Search Results}

A \emph{collection} includes all searchable images, videos, and 3D models. The museum treats each file as a \emph{media object}. A video result may point to a specific time segment, while a 3D model is represented by rendered views during retrieval. Each result therefore needs a link to the original media object shown in the museum.

Queries enter the system in two ways. Users can type a description or select an exhibit from an earlier exhibition as the starting point for a new search. In both cases, the backend produces ranked \emph{search results}. Each result refers to a media object. It also contains the information needed to show it as an exhibit.

\subsection{Media-Specific Exhibits}

An \emph{exhibit} is the presentation of a search result. Two-dimensional and three-dimensional media use different presentation structures. Figure~\ref{fig:concept-presentation-templates} shows how these structures are used.

Images and videos appear as framed exhibits. The content keeps its original aspect ratio, while the frame has the same thickness around it. This gives media with different dimensions a common appearance. A video exhibit also preserves the time reference of the result by starting playback at the retrieved segment.

3D models are presented in a dedicated display space. Visitors can rotate them and view them from different sides. They can also open a model in a separate room, where its scale is easier to understand in relation to the room.

\subsection{Spatial Placement Areas}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.9\textwidth]{Figures/ch04-05-concept-placement-areas.pdf}
  \caption[Conceptual placement areas in the museum room]{Conceptual placement areas in the museum room. The orange wall area marks where images and videos can be displayed, while the red floor areas define positions for 3D exhibits. [\hyperref[generative-ai]{ChatGPT}].}
  \label{fig:concept-placement-areas}
\end{figure}

The room has two types of placement areas, as shown in Figure~\ref{fig:concept-placement-areas}. Images and videos are placed on the walls, while each floor area can contain one 3D object. Based on the media type of a result, the system assigns it to the correct area.

\enlargethispage{\baselineskip}
\subsection{From Search Results to an Exhibition}

An \emph{exhibition} contains the exhibits created from one query. Since the room has limited space, it cannot show the complete ranking. Images and videos share the wall areas, while 3D models use the floor areas. Results are considered in ranking order and assigned to a matching free area. A result is skipped when no area is available. The resulting subset becomes the exhibition and keeps the order of the original ranking.


\section{Exploration Flow}
\label{sec:concept-exploration-model}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.9\textwidth]{Figures/ch04-02-exploration-loop.pdf}
  \caption[Continuous exploration loop]{
    Continuous exploration cycle of the VR museum. A text query starts a semantic search and creates an exhibition. Selecting one of the exhibits starts the next search, creating a cycle.
  }
  \label{fig:concept-exploration-loop}
\end{figure}

The museum is designed for a sequence of searches, as shown in Figure~\ref{fig:concept-exploration-loop}. A query creates an exhibition, and any exhibit can then become the basis of the next query. In this way, users can explore the collection step by step.

\subsection{Guided Entry and Settings}

Visitors first see a menu before they enter the museum. They can change the backend connection, select the media types, and set the movement speed. An optional tutorial explains navigation and the main actions. The menu can be opened again at any time, while the current exhibition remains open in the background.

\subsection{Entry and Exploration}

The process starts with a text query. It defines a topic and creates the first exhibition. Visitors can then move through the room and inspect individual exhibits. Selecting an exhibit as a new query or entering another text query creates a new exhibition.

\subsection{Similarity-Based Continuation}

Every exhibit can become the starting point of a similarity search. The \emph{Similar} action finds related media objects, and the results form a new exhibition.

A text search can cover many different topics. Selecting an exhibit makes the next search more specific. This forms the main exploration cycle. Visitors can repeat this process as often as they want.
