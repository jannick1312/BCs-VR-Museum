\setlength{\emergencystretch}{3em}
\small

The evaluation used an English-language Google Forms questionnaire containing 41 questions in ten sections. Questions 11--13 and 41 were optional. All other questions were required. Unless stated otherwise, evaluation statements used the following five-point response scale: \emph{Strongly disagree}, \emph{Disagree}, \emph{Neutral}, \emph{Agree}, and \emph{Strongly agree}.

\section{System Usability Scale}

The introductory text was: \emph{Please indicate how strongly you agree or disagree with each statement.}

\begin{enumerate}
  \item I think that I would like to use this system frequently.
  \item I found the system unnecessarily complex.
  \item I thought the system was easy to use.
  \item I think that I would need the support of a technical person to be able to use this system.
  \item I found the various functions in this system were well integrated.
  \item I thought there was too much inconsistency in this system.
  \item I would imagine that most people would learn to use this system very quickly.
  \item I found the system very cumbersome to use.
  \item I felt very confident using the system.
  \item I needed to learn a lot of things before I could get going with this system.
\end{enumerate}

\section{General Information}

\begin{enumerate}
  \setcounter{enumi}{10}
  \item How would you assess your general affinity for technology?\\
  \emph{Very low; Low; Medium; High; Very high}

  \item Which VR headsets have you already used? (Multiple selections possible)\\
  \emph{Meta Quest; Vive Focus 3; I don't know}

  \item How much experience do you have with virtual reality (VR) headsets?\\
  \emph{No experience; Little experience (one to two uses); Some experience (two to five uses); A lot of experience (more than five uses)}
\end{enumerate}

\section{Standalone Quest 3 --- Usage}

\begin{enumerate}
  \setcounter{enumi}{13}
  \item Did you use the standalone version on a Meta Quest 3?\\
  \emph{Yes; No}
\end{enumerate}

A \emph{Yes} answer displayed the following evaluation section. A \emph{No} answer continued with the Vive Focus 3 usage question.
